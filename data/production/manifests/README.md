# Approved Production Content Manifests

The Production importer accepts JSON manifests only from this directory. A
manifest is a complete content snapshot for one release, not a database dump or
a pointer to demo fixtures.

No Production manifest is committed yet. Add one only after the primary
professor approves the exact topics, questions, child content, safe pattern
metadata, source-file hashes, expected counts, and canonical content hashes.
The manifest must identify the professor by immutable institutional user ID and
must not contain an email-only signature, role label, shared secret, or private
source content.
