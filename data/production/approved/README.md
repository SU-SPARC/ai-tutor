# Approved Production Content Sources

This directory is reserved for professor-reviewed, public-safe source artifacts
referenced by an approved Production content manifest. Every referenced file is
hashed with SHA-256 and the importer verifies the hash before database access.

Do not place demo/test fixtures, raw retrieval chunks, private textbook text,
extracted source material, embeddings, generated drafts, student records,
session data, or logs here. Professor approval applies to the exact file hash;
changing a file requires a new review and manifest.
